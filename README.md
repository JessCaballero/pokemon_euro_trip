Las escenas que funcionan en este demo son: 
Madrid: Escena de elecciones. 
El Retiro: Esta escena solo es conversación con un Pidgey
Puerta del Sol: Para ganar monedas DEBES de ir a esta escena, aquí hay una pelea corta con Meowth y es aquí donde se usa brevemente la PokeAPI
Estación del Tren: Sevilla es la única escena que lleva a otras sub escenas funcionales. 
Sevilla: Escena de elecciones. 
Plaza de España: Interacción con Oricorio. Aquí hay un guiño a el ejercicio de "adivina un número del 1 al 10" al acertar, Oricorio te enseñará la Sevilla. 
Tienda: Funciona como interacción.
